Detailed Description

Storage block with automatic compression and file management.

Represents a single storage block that can be read from file, created in memory, and automatically compressed when written back to storage. The block handles compression/decompression transparently. Modified blocks are written explicitly by the reader before eviction or checkpoint.

Blocks are typically managed through storage_block_reader which provides caching and handles the complex interaction between the block, file storage, B-tree index, and memory allocator.

bool compio::block::write_back ( )

Write the block to the archive if it has unsaved modifications.

Compresses the data, places it at a newly allocated address (the old place is released) and records that address in the index. The block stays usable and becomes unmodified only on success.
