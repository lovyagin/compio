Detailed Description

Storage block with automatic compression and file management.

Represents a single storage block that can be read from file, created in memory, and automatically compressed when written back to storage. The block handles compression/decompression transparently and manages its own lifecycle through RAII - modified blocks are automatically compressed and written to file when the block is destroyed.

Blocks are typically managed through storage_block_reader which provides caching and handles the complex interaction between the block, file storage, B-tree index, and memory allocator.

Destructor - automatically compresses and writes modified blocks.
