Detailed Description

Configuration structure for archive creation.

Contains all settings for archive behavior including compression, indexing, caching, and memory allocation strategies.

◆ allow_compressor_change

bool compio_config::allow_compressor_change

Opening an archive written with another compressor (default: false, the open fails with EINVAL). When true, the compressor above compresses the blocks written from now on and is recorded in the header at the next publication; stored blocks keep their codec. Blocks of a custom codec need compio_register_compressor() before they are read.

int compio_config::compression_threads

Threads that compress the blocks of one write-back (default: 0 = one per hardware thread; 1 = compress on the calling thread only). The blocks are placed and indexed in order by the calling thread. An external compressor (COMPIO_COMPRESS_CUSTOM and above) is always called from one thread.

◆ enable_wal

bool compio_config::enable_wal

Maintain the write-ahead log (default: true). When false, writes go straight to the archive with no journaling: maximum write throughput, but NO crash safety and NO recovery on reopen. Intended for scratch/throwaway archives or benchmarking the cost of journaling itself.

◆ fill_holes_with_zeros

bool compio_config::fill_holes_with_zeros

Give the storage under freed regions back to the filesystem (default: false). A hole is punched (Linux: fallocate, macOS: F_PUNCHHOLE, Windows: sparse file with zeroed ranges), which makes the container a sparse file: its size stays the same while its disk usage shrinks. Where the platform or the filesystem cannot do that, the region is overwritten with zeros instead.

◆ fragmentation_threshold

uint8_t compio_config::fragmentation_threshold

Compact the archive when free regions take more than this percentage of the container (default: 30; 100 disables automatic compaction). Checked when the archive is closed and at every header publication (compio_flush, compio_end_batch, a checkpoint at wal_max_size_bytes); a publication counts only space that stayed free since the previous one. compio_defragment() compacts regardless of it.

◆ max_files

int compio_config::max_files

Expected number of files; memory for that many entries is reserved (default: COMPIO_MAX_FILES, 0 = default). Not a limit and not stored in the archive: the table grows up to COMPIO_MAX_FILES_LIMIT files.

◆ wal_max_size_bytes

uint64_t compio_config::wal_max_size_bytes

WAL size in bytes that forces a flush with header publication, which truncates the WAL (default: 64 MB, 0 = unlimited). Checked after each write, insert and erase; inside compio_begin_batch() it waits for compio_end_batch().
