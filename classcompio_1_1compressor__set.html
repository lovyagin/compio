Detailed Description

Compressors an archive can encode and decode with.

New blocks are packed with the active compressor. A block records the compression_type of the compressor that packed it, and is unpacked by the compressor registered under that type; the built-in algorithms are always present, an external one has to be registered. Callers hold the archive lock: changes need it exclusively, lookups shared.
