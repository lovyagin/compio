=============================

This analysis compares the current multimap-based allocator
with a Segregated Free List (SFL) implementation.

Current Implementation:
  - Doubly-linked list sorted by offset
  - std::multimap<size, block*> for size-based lookups
  - Best-fit: O(log n) using lower_bound
  - First-fit: O(n) linear scan

Segregated Free List:
  - 12 buckets for size ranges: [0-64], [65-128], ..., [>64KB]
  - Each bucket is a simple linked list
  - Best-fit: O(n/k) where k is number of buckets
  - First-fit: O(1) to O(n/k) typically
