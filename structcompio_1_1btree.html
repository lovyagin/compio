Detailed Description

B-Tree, that stores addresses of compressed blocks in archive file, with access by their start position. B-Tree nodes are stored in archive file.

Provides efficient key-value storage and retrieval for compressed block addresses within archive files. Supports standard B-Tree operations including insertion, deletion, range queries, and key updates.

◆ set_header()

void compio::btree::set_header ( smart_infile_object< header >  new_header)
inline

Re-point the B-Tree at a new header storage.

The double-buffered header write replaces the archive's header smart pointer with a fresh storage object. The B-Tree caches its own copy that shares the header storage (it reads/writes index_root through it), so it must be re-synced to the new storage or the two diverge and index updates are lost. Caller must hold the archive lock.
