int(* compress )(const struct compio_compressor *comp, void *dst, uint64_t *dst_size, const void *src, uint64_t src_size)
 Compress src_size of bytes from src buffer into dst buffer. On success, return 0 and write real size of compressed data into dst_size. If dst buffer is too small, return non-zero code and set errno = ENOBUFS.

 Decompress src_size of bytes, that was previously compressed with the same compressor, from src buffer into dst buffer. On success, return 0 and write real size of decompressed data into dst_size. If dst buffer is too small, return non-zero code and set errno = ENOBUFS.
