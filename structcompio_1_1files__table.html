Detailed Description

Files table: name, size and id of every logical file.

On disk the table is a sequence of variable-length records name_len (u16) | size (u64) | file_id (u64) | name (name_len bytes), little endian, without padding or free slots. It is always rewritten as a whole to a new place (copy-on-write), so records never need room to grow in place.
