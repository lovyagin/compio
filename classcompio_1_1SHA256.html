Detailed Description

SHA-256 cryptographic hash calculator.

Provides an incremental SHA-256 hash computation interface. Supports both streaming updates and one-shot computation.

Example:
SHA256 sha;
sha.update(data, length);
uint8_t hash[32];
sha.finalize(hash);
// Or one-shot:
std::string hash_hex = SHA256::compute(data, length);

void compio::SHA256::finalize ( uint8_t *  hash)

Finalizes hash computation and outputs result.

Completes the SHA-256 computation and writes the final 32-byte hash. After calling finalize(), the hasher is in an unusable state and cannot be updated.

Parameters
[out]hashPointer to 32-byte buffer for hash output. Must not be nullptr.
Note
After finalize(), do not call update() or finalize() again on this instance.
Output hash is in binary format (raw bytes).
